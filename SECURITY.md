# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by email to
[security@claudioed.com](mailto:security@claudioed.com). Do not open a public
issue for a potential security vulnerability.

Include a description of the issue, affected component or version, steps to
reproduce, and any suggested mitigation. We will acknowledge receipt and work
with you on coordinated disclosure.

## Supported Versions

Security fixes are supported on the active development branch, `develop`, and
on the current release branch, `main`. Older release tags and branches are not
supported.
